# SaveClip — загрузчик видео для Android

Скачивает видео и звук с YouTube, TikTok, Instagram и многих других сайтов по ссылке.
Тёмный дизайн, прогресс загрузки, история, кнопка «Поделиться → SaveClip».

Работает на Android 10 и новее. Файлы сохраняются в **Загрузки/SaveClip**.

## Как получить APK без программирования (через GitHub, бесплатно)

1. Зарегистрируйтесь на github.com.
2. Создайте новый репозиторий: кнопка **New**, любое имя, например `SaveClip`.
3. Нажмите **uploading an existing file** и перетащите **все файлы и папки из архива**.
   Папка `.github` скрыта в некоторых системах — включите показ скрытых файлов, без неё сборка не запустится.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка запустится сама и займёт около 5–10 минут.
6. Когда появится зелёная галочка, откройте сборку и скачайте **SaveClip-apk** внизу страницы.
7. В архиве будут несколько APK. Для почти всех современных телефонов нужен файл с **arm64-v8a** в названии.
   Если он не ставится, попробуйте **armeabi-v7a**.
8. Перекиньте APK на телефон и установите. Android попросит разрешить установку из этого источника — разрешите.

## Сборка в Android Studio

Откройте папку проекта в Android Studio → **Build → Build APK(s)**.

## Использование

- Скопируйте ссылку и нажмите на значок вставки, или в приложении YouTube/TikTok/Instagram нажмите **Поделиться → SaveClip**.
- Выберите «Видео» с качеством или «Аудио MP3» и нажмите «Скачать».
- Если сайт перестал скачиваться: **⋮ → Обновить движок**.

## Ограничения

- Первый запуск занимает до минуты: приложение распаковывает загрузчик.
- Некоторые видео в Instagram доступны только после входа в аккаунт, такие скачать не получится.
- Во время загрузки не закрывайте приложение.
- Скачивайте только свои видео или те, на которые у вас есть разрешение автора.

Построено на [youtubedl-android](https://github.com/yausername/youtubedl-android) (yt-dlp + ffmpeg).
